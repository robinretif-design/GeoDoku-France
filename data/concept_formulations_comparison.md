# Comparatif de formulations - concept central GevoCroisee

Date : 13/06/2026

Objectif : tester des formulations tres courtes pour expliquer le principe central sans modifier les regles, l'interface ou le fonctionnement.

Contrainte : chaque formulation reste entre 15 et 25 mots.

## Selections recommandees

### Formulation la plus claire

**#1 - "Plusieurs departements peuvent convenir, mais les meilleurs croisements rapportent plus. A vous d'optimiser toute la grille."**

Raison : elle dit explicitement les trois idees critiques : plusieurs reponses, difference de score, optimisation globale.

### Formulation la plus engageante

**#7 - "Ne cherchez pas juste une reponse : cherchez le departement qui fera vraiment grimper la grille."**

Raison : elle transforme la consigne en defi. Elle est moins descriptive, mais plus stimulante.

### Formulation la plus adaptee a un ecran mobile

**#2 - "Une case peut accepter plusieurs reponses. Le score recompense celle qui colle le mieux aux deux indices."**

Raison : deux phrases courtes, lecture rapide, vocabulaire simple, excellente adequation avec le moment ou le joueur touche une case.

## Recommandation de test

Pour un test utilisateur, comparer prioritairement :

1. #1 pour la clarte d'accueil ;
2. #2 pour une aide contextuelle dans la grille ;
3. #7 pour une version plus engageante.

Hypothese a verifier : la formulation #2 devrait reduire le plus vite la confusion "une seule bonne reponse", tandis que #7 devrait mieux donner envie d'optimiser.
