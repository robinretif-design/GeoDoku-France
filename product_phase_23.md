# Phase 23 - Evolution du Concept C vers Concept C+

## Objectif

Faire evoluer le Concept C retenu vers une version finale plus territoriale, sans perdre ses qualites principales :

- lisibilite mobile ;
- memorisation ;
- lecture favicon/PWA ;
- sensation de jeu quotidien ;
- croisement d'idees ;
- decouverte des territoires francais.

Aucun asset actif n'a ete remplace et aucun fichier applicatif n'a ete modifie.

## Variantes produites

### C1 - Hexagone discret

Structure du Concept C conservee : quatre tuiles, croisee centrale, point de decouverte.

Ajout territorial : un hexagone simple en arriere-plan du symbole, assez visible pour evoquer la France mais assez discret pour ne pas transformer l'icone en carte.

Palette :

- `#17213A`
- `#1F8A70`
- `#FF6B4A`
- `#F7C948`
- `#F4F6F0`

Evaluation : meilleure synthese entre jeu, croisement, territoire francais et lisibilite favicon.

### C2 - Maillage doux

Structure du Concept C conservee.

Ajout territorial : lignes courbes simplifiees evoquant un maillage de territoires ou de limites sans dessiner une carte identifiable.

Palette :

- `#17213A`
- `#238A7D`
- `#FF7058`
- `#F2C94C`
- `#E8EFE6`

Evaluation : la plus territoriale dans l'intention, mais aussi la plus chargee en petit format.

### C3 - Repere minimal

Structure du Concept C conservee.

Ajout territorial : repere cartographique abstrait au centre, traite comme point de decouverte plutot que comme pin classique.

Palette :

- `#17213A`
- `#167C80`
- `#FF6B4A`
- `#F7C948`
- `#F4F6F0`

Evaluation : tres lisible et tres mobile, mais l'evocation est plus cartographique que specifiquement francaise.

## Classement

1. C1 - Hexagone discret
2. C3 - Repere minimal
3. C2 - Maillage doux

## Recommandation finale

Recommandation : **C1 - Hexagone discret**.

Cette variante conserve le meilleur du Concept C : symbole simple, fort contraste, lecture immediate en favicon, logique de jeu mobile-first et point de decouverte central. L'hexagone ajoute une reference francaise claire sans utiliser de carte detaillee, de contour complexe, de departement identifiable ni de style institutionnel.

Direction finale proposee :

`quatre idees` + `croisee centrale` + `point de decouverte` + `hexagone discret`.
